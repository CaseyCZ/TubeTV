# TubeTV

Native Apple TV (tvOS) client experiment built with **Swift + SwiftUI**.

## First milestone

- Native tvOS interface controlled with Apple TV Remote
- Home
- Search
- Video detail
- AVPlayer playback
- Architecture for stream quality up to 4K/60/HDR when available
- Captions with Czech as the preferred language and translation support planned
- YouTube account/subscriptions/history/playlists planned

TubeTV is an independent project and is not affiliated with YouTube, Google, or SmartTube.
